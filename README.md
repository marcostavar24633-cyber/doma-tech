# DOMA TECH — демонстрационный сайт

Опубликованная версия DOMA TECH — статический демонстрационный сайт для сравнения и подбора посудомоечных машин.

**Сайт:** https://marcostavar24633-cyber.github.io/doma-tech/

## Что реализовано

- Адаптивная витрина на русском языке.
- Категории посудомоечных машин.
- Демонстрационный подбор по параметрам.
- Примеры моделей с ориентировочными характеристиками и ценами.
- Локальные фильтры и сортировка каталога.
- Таблица сравнения моделей.
- Раскрывающиеся характеристики и FAQ.
- Демонстрационная форма без отправки и сохранения данных.
- Базовые средства доступности: клавиатурный фокус, skip-ссылка, подписи полей, reduced motion.

## Технологии и структура опубликованной версии

Публичная версия работает без backend и собирается из каталога `public/`.

- `public/index.html` — разметка страницы и SEO-метаданные.
- `public/styles.css` — стили и адаптивная верстка.
- `public/script.js` — интерактивность на стороне браузера.
- `public/favicon.svg` — иконка сайта.
- `.github/workflows/deploy-prototype.yml` — публикация на GitHub Pages.

## Локальный просмотр

Можно открыть `public/index.html` непосредственно в браузере. Для локального HTTP-просмотра из корня репозитория подойдёт любой статический сервер, например:

```bash
python -m http.server 8000 --directory public
```

Затем откройте `http://localhost:8000`.

## Публикация

Workflow GitHub Actions запускается при изменениях в `public/**` или в файле `.github/workflows/deploy-prototype.yml`. Он копирует содержимое `public/` в Pages artifact и публикует его через GitHub Pages.

Ручной запуск доступен через вкладку **Actions** репозитория.

## Ограничения демонстрационной версии

- Это не работающий интернет-магазин и не система приёма заказов.
- Формы не отправляют и не сохраняют введённые данные.
- В проекте не используются база данных, авторизация, серверное API или платёжная система в опубликованной версии.
- Цены и характеристики моделей приведены как справочные ориентиры; их нужно перепроверять у продавцов и по точной модификации.
- Наличие товаров, цены DOMA TECH, доставка, гарантия и условия продажи не подтверждены.
- Индексация поисковиками отключена через `noindex,follow` до реального запуска коммерческого проекта.

## Отдельная серверная заготовка в репозитории

В корне репозитория сохранены файлы серверной версии (`server.js`, `package.json`, `Dockerfile`, `docker-compose.yml`, `data/`, `uploads/` и `.env.example`). Они **не входят в публикацию GitHub Pages** и не используются текущей статической страницей.

Серверную заготовку нельзя считать готовой к коммерческому запуску только на основании наличия этих файлов. Перед её отдельным развёртыванием необходимы самостоятельная проверка безопасности, конфигурации, обработки персональных данных, резервного копирования и эксплуатационных требований. Не запускайте её на публичном сервере без такой проверки.

## Перед коммерческим запуском

1. Подтвердить продавца, ассортимент, цены и наличие.
2. Указать реальные контакты и условия оплаты, доставки, возврата и гарантии.
3. Подготовить юридические документы и корректные согласия, если будут собираться персональные данные.
4. Решить, нужна ли серверная часть; не подключать её автоматически к статическому прототипу.
5. Провести браузерные тесты на мобильных устройствах, клавиатуре и с экранным диктором.
6. После готовности проверить SEO-метаданные и только затем снять `noindex`.
